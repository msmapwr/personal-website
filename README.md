# Msmapwr Personal Website

<div align="center">

A lightweight personal website built with pure HTML, CSS and JavaScript.

Inspired by Microsoft Fluent Design and Windows desktop experience.

</div>


## ✨ Preview

A personal digital space designed with:

- Fluent Design System
- Windows 11 visual language
- Acrylic materials
- Smooth interactions
- Lightweight vanilla web technology


The goal is to create a website that feels like a personal operating system:

> A place where creativity, code and ideas come together.



## 🚀 Features


### Fluent Design

- Acrylic glass material
- Reveal-style hover effects
- Microsoft Fluent color system
- Windows-inspired layout
- Soft depth and elevation


### Interactive Experience

- Dynamic Fluent light background
- Dark mode support
- Smooth scrolling navigation
- Project filtering
- Project dialog
- Typing animation


### Lightweight Architecture

No frameworks.

No build tools.

No dependencies.


Built only with:

- HTML
- CSS
- JavaScript
